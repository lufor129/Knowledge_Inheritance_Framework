# 只留簡報：拿掉手冊，長說明做成深入頁

2026-10-26 定案，取代 ADR-0006 裡「手冊選配、兩邊一樣重要、雙向指紋」的部分；ADR-0006 其他的決定照舊（簡報必備、每頁要有圖、新寫的說法要附出處、讀者測試也測簡報）。

每個知識庫的內容只剩一份簡報。一頁放不下的長說明（推導、表格、很多出處），做成接在主頁後面的深入頁：照順序翻會經過，標「深入・可略過」，可以一鍵跳過；畫面放圖和重點，長說明放在畫面下方、預設展開；學習路徑的時間和進度不算深入頁。原本手冊首頁的全景圖和速覽交給入口網站：全景圖照部分和章自動排，各章的先修畫成箭頭；每章的速覽寫在章檔開頭，必填；主題索引從術語表自動產生。查找只根據簡報（主頁、深入頁、自我檢查）。

## Considered Options

- **只拿掉手冊網站，手冊文字留著，在簡報裡展開**：新人只看到簡報，但傳承者改內容時，簡報頁和小節還是要兩邊對照、兩邊同步。
- **長說明放在每頁下方的「詳細」區塊，或併進旁白**：不用多一種頁；但旁白是講稿、詳細是補充，混在一起不好分，也看不出哪些是「可以略過」的內容。
- **手冊不搬，Git 找得回來就好**：最省事，但手冊獨有的說明、出處和術語會從正式內容消失，主題索引也找不到只寫在手冊的詞。

## Consequences

- 拿掉小節 id、「每個小節都要有簡報頁」、頁序裡的雙向指紋、手冊網站和手冊的讀者測試；頁 id 照舊建立後不改名。
- 檢查程式多擋：每章要有速覽、先修要指到存在的章、深入頁要接在主頁後面、術語表的「第一次出現」要指到頁；深入頁說明的每一段也算「新寫的說法要附出處」。
- 搬家時，手冊的說明照搬成深入頁，算舊內容：沒出處的數字列進可以慢慢補的清單，不因為搬家刪內容。
- 先修只標跨章、真的用得到的；手畫全景圖上像「量到的數字回頭修正微影」這種不是先修的關係，改寫進速覽或旁白。
- 文字版（整份可以列印）先不做；之後需要，可以從簡報自動產生。
