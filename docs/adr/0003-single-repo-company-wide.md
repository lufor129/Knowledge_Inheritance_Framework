# 框架和所有知識庫放在同一個 repo，全公司都能看

我們把框架和所有知識庫放在同一個 repo。新人和傳承者只要拿一個 repo 就能工作，跨知識庫查找也最簡單。代價是無法做「只有某個團隊能看」的知識庫：Git 沒辦法限制誰能讀某個資料夾。所以需要限制閱讀範圍的知識，不放進這套框架。

## Considered Options

- **框架一個 repo，每個知識庫各一個 repo**：可以用 repo 權限做到「限團隊」，但要多拿好幾個 repo，跨庫查找要靠清單，框架更新也要同步到每個 repo。
- **一個大 repo，只有限團隊的知識庫另外開 repo**：兩種放法並存，規則比較不一致。
