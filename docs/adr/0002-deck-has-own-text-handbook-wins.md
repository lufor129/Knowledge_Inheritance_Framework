# 簡報可以自己寫文字，但手冊仍是正本

ADR-0001 原本要求簡報從手冊讀取文字。後來改為簡報可以用自己的文字，因為上台講解要配合動畫重新編排，講法也和閱讀時不同。手冊仍是正本：簡報每一頁都標出它對應的小節；修改小節時，Agent 必須在同一個變更提案裡檢查並更新對應的簡報頁；兩邊說法不一致時，以手冊為準。

## Consequences

- 同一個知識會有兩份文字，所以「改小節就要一起檢查簡報頁」一定要做到。Claude Code 寫在規則檔裡的指示不保證會被遵守，所以這件事交給檢查程式：頁序裡每一組「簡報頁 → 小節」都記下小節文字的指紋（短雜湊值），小節一改，指紋就對不上，程式會點名要重看的簡報頁。Agent 改好或確認過那一頁之後，才更新指紋。
- 半導體範例搬進來時，簡報的文字可以大致保留，只需要從簡報抽出手冊，並替每一頁標上對應的小節。
