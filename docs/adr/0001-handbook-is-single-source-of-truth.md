# 手冊（Markdown）是唯一正本，簡報只讀取正本

半導體範例把重點、比喻、數字和講稿直接寫在簡報的 JS 裡。傳承者要改一句話就得改程式碼，Agent 新增或查找也要在動畫程式裡翻找。我們決定：知識只寫在手冊的 Markdown 裡，簡報用小節 id 讀取文字，簡報程式只負責動畫和版面。代價是現有的半導體簡報要搬遷，簡報引擎也要能讀取手冊。

## Considered Options

- **手冊是正本，簡報另外維護，由 Agent 比對兩邊**：不用搬遷，但兩份文字遲早會不一致，新人會看到兩種說法。
- **手冊和簡報各自獨立**：最省事，但同樣會不一致，也沒有任何一份能當成標準答案。
