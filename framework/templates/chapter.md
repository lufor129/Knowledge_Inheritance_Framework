# 章名

- 速覽：兩三句：這一章在講什麼、學完會知道什麼、為什麼排在這裡。
- 先修：要先看完的章名（沒有就刪掉這一行；別的知識庫的章寫成「cv › 影像分類」）

<a name="xxx1"></a>
## 一頁講一個概念：標題就是重點

- 短標題：給總覽和講者視窗看的短標題
- 建議：3 分
- 圖：互動圖名稱（或 assets/img/檔名.jpg｜說明）

結論：標題下面那一句，講結論。

重點：
- 三到四點，一行一點；術語第一次出現附英文，例如「量子穿隧（Quantum Tunneling）」
- 數字一定附出處[^xxx1-1]

比喻（chip）：能用生活比喻就用一個。

旁白：
講稿：自學的人打開「旁白」看得到，講者按 N 看得到。

[^xxx1-1]: 出處：論文、文件位置、網址，或「某某（部門）口述，YYYY-MM」

## 一頁放不下的長說明，做成深入頁

- 深入：xxx1
- 圖：同主頁
- 建議：3 分

重點：
- 三到五點，講這一頁的說明在講什麼

說明：
長說明照一般的 Markdown 寫：多段、### 小標題、清單、表格、> 開頭的引言、圖片、出處註腳。
