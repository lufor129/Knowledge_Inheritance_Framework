# 讀者測試

開變更提案之前做，用來找出沒寫清楚的地方。

1. **出題**：用改過那一章的常見問題（深入題除外）。這次改的小節沒有對應的題目時，替每個改過的小節出一題「讀完這一節應該答得出來」的題目。
2. **找一個外行讀者**：開一個子 agent（Agent 工具，它看不到這段對話），只給它改過那一章的全文和題目，指示它：
   「你是完全沒有這個領域背景的新人。只能根據下面這一章回答；章裡沒寫的，就回答『這章沒寫』，不要用你自己的知識。」
3. **對答案**：答不出來、答錯、或用了章裡沒有的知識，都算沒過。
4. **改寫**：沒過的地方通常是術語沒解釋、跳了一步、缺了「為什麼」。改寫後再測一次。
5. **完成**：全部題目都答得出來。在提案說明的「影響」寫「讀者測試：n/n 題答對」。
