# 讀者測試

開變更提案之前做，找出新人讀不懂的地方：寫的人覺得清楚，沒有背景的人不一定看得懂。

1. **出題**：`python3 framework/tools/reader_test.py <知識庫>`。它找出這個分支改過的章，每一章產生一份題目卷和一份答案卷：
   - 簡報的章：題目卷是那一章每一頁的文字和旁白，題目是那一章的自我檢查。互動圖讀者看不到，所以測的是文字和旁白講不講得清楚。
   - 手冊的章：題目卷是那一章的內文，題目是那一章的常見問題。
   深入題不考。改過的頁或小節沒有題目時它會停下來；用 `--ask "<頁 id 或小節 id>：<題目>"` 替每一個補一題「讀完應該答得出來」的題目，再跑一次。
2. **外行讀者作答**：每一章開一個子 agent（Agent 工具），只跟它說「讀 <題目卷>，照裡面的指示作答」。題目卷已經寫好外行讀者的指示，也拿掉了題目的答案；多給別的資料或提示，測出來就不準了。
3. **對答案**：拿它的回答對照答案卷。答不出來、答錯、或用了章裡沒有的知識，都算沒過。
4. **改寫**：沒過的地方通常是術語沒解釋、跳了一步、缺了「為什麼」。改寫後從第 1 步再測一次。

完成：全部題目都答對。開提案時用 `proposal.py … --reader <n/n>` 把結果寫進說明。
