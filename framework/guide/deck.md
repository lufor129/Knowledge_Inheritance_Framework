# 簡報

簡報是選配，可以用自己的文字，但說法以手冊為準。頁序 `kb/<知識庫>/deck/order.md` 記錄每一頁對應哪些小節，以及那些小節的指紋。

## 小節改了之後：簡報頁要跟上

check.py 會點名「對應的小節改過了」的簡報頁。每一頁都要：

1. 在 `deck/slides/` 找到那一頁（`grep -n "id: '<頁id>'" kb/<知識庫>/deck/slides/*.js`），和改過的小節對照。
2. 說法不一致時，照手冊改簡報頁的文字：標題、thesis、重點、數字卡、比喻卡、講稿。一致就不用改。
3. 改好或確認之後更新指紋：`python3 framework/tools/check.py --fp <知識庫> <頁id …>`

指紋的意思是「有人對照過這一頁」，所以一定先看過頁面，再跑 `--fp`。

## 新增對應

新的小節有簡報頁在講時，在 order.md 那一頁後面加上 `→ <小節id>`（已經有對應就用逗號接在後面），再跑 `--fp`。

## 做新的簡報頁

照半導體範例的樣子：

- 每頁講一個概念；標題下面一句話講結論（thesis）。
- 右邊依序是重點（三到四點）、數字卡（出自對應小節的一個數字；沒有好數字就放一句話重點）、比喻卡。
- 左邊建議放可以操作的互動元件。
- 講稿寫在 `notes`，只存在簡報裡。

頁面寫在 `deck/slides/*.js`，用 `Deck.add({ id, part, chap, title, thesis, render, init, notes })` 註冊；版面輔助函式在 `framework/engine/widgets/core.js`（`U.side`、`U.seg`、`U.stepper`……）。加進 order.md 才會播放。

## 放影片

示範影片（例如物件偵測的結果）可以放在簡報頁裡，建置時會內嵌進單一 HTML，離線也能播：

- 影片放在 `kb/<知識庫>/assets/video/`，格式用 mp4（H.264）或 webm；和圖片一樣要列進 `assets/SOURCES.md`，寫說明和出處。
- 整支影片會塞進 HTML，所以只放幾秒鐘、去掉聲音、縮到需要的解析度，例如：`ffmpeg -i 原檔.mp4 -t 8 -an -vf scale=960:-2 -c:v libx264 -crf 28 -movflags +faststart assets/video/檔名.mp4`
- 在 `render` 裡寫 `U.video('assets/video/檔名.mp4')`：預設靜音、循環、進頁自動播放，點畫面暫停／繼續，離頁自動停止。要控制列或不要循環時加選項，例如 `U.video('assets/video/檔名.mp4', { controls: true, loop: false })`；其他選項見 core.js。
- 放進 `.fig-canvas` 會填滿主圖面板。

## 用 Markdown 寫簡報頁

簡報頁也可以寫成 Markdown：文字在 `deck/<部分>/<章>.md`，互動圖在 `deck/figures/*.js`。舊的程式頁（`deck/slides/*.js`）照常播放，兩種可以混用；播放順序一樣看頁序 order.md，加進頁序才會播放。

- 檔案：`kb/<知識庫>/deck/<數字-英文>/<兩位數字-英文>.md`，編號跟手冊一樣，例如 `deck/2-manufacturing/05-gate.md` 是第二部分第 5 章。`00-` 開頭的檔放部分的開場、總覽，不屬於任何一章。第一行寫 `# 章名`。
- 一頁是一個錨點加標題，底下是欄位：

  ```
  <a name="hk1"></a>
  ## 絕緣牆的兩難：電場要過得去，電子不要過去

  - 短標題：閘極絕緣層：電場過、電子不過
  - 英文：Gate Dielectric · High-k
  - 建議：5.2 分
  - 圖：hk-wall

  結論：閘極隔著一道絕緣牆，用**電場**控制通道……

  重點：
  - **電場要過得去**：牆越薄，閘極越控制得住通道
  - 牆每薄 0.2 nm，漏電大約多 10 倍[^hk1-1]

  數字卡：約 1.2 nm｜2000 年代初期二氧化矽已經薄到這裡

  比喻（wall）：隔著牆用磁鐵（閘極）吸鐵片（通道的電子）……

  旁白：
  第五章：閘極。回到電晶體的核心……

  [^hk1-1]: 出處：……
  ```

| 欄位 | 寫法 |
|---|---|
| 短標題、英文 | 總覽和講者視窗用的短標題；英文副標可以不寫 |
| 建議 | 這一頁大約講幾分鐘；入口網站用它算每章要看多久 |
| 圖 | 互動圖的名稱；或圖片、影片：`assets/img/檔名.jpg｜說明`、`assets/video/檔名.mp4｜說明`（要列進 assets/SOURCES.md） |
| 結論 | 標題下面那一句 |
| 重點 | 三到四點，一行一點 |
| 數字卡 | `數字｜說明` |
| 比喻 | `比喻（圖示）：` 後面接文字；圖示名稱見 `framework/engine/widgets/anim.js` 的 ICON，不寫就用預設 |
| 旁白 | 講稿，可以多段，空行分段；寫在欄位的最後。開頭寫【可略】【提示】的段落只給講者看 |

- 行內寫法：`**粗體**`、`` `程式` ``、`[文字](網址)`、`[^註腳]`，也可以直接寫 HTML。註腳是出處，名稱用「頁 id-編號」，定義寫在那一頁最後；頁面上數字後面會出現小標號，點了看出處，最後一頁自動整理成「出處」。
- 頁碼引用：要說「第幾頁」時寫 `[[頁:頁id]]`，顯示時換成「第 N 頁」，頁序調整了也不會錯。舊的程式頁也這樣寫，不要寫死頁碼。

### 互動圖

```js
Fig.add('hk-wall', {
  render: page => `${U.figHTML('hw-cv', '圖框標題', '')}<div class="controls">${U.range('hw-t', '厚度', 0.6, 4, 0.1, 2.5, ' nm')}</div>`,
  init(el, ctx, page) { /* 綁控制元件、畫圖；ctx.raf 的動畫離頁自動停止 */ },
  meters: [['hw-m', '漏電']],   // 放在右邊重點下面，init 裡用 U.setMeter 更新；不用可以不寫
  layout: 'w66'                // 左右比例：預設、w66、w50、full；side: false 就不放右欄
});
```

輔助函式在 `framework/engine/widgets/core.js`、`anim.js`（`U.figHTML`、`U.range`、`U.seg`、`U.stepper`、`U.canvas`……）。互動圖只畫圖，不放要讓新人讀的文字；文字都寫在 Markdown，查找、搜尋和讀者測試才讀得到。

### 自我檢查題目

章檔最後可以加 `## 自我檢查`，格式跟手冊的常見問題一樣，`相關：` 寫頁 id。建置時，這一章的題目，加上手冊同一個編號那一章的常見問題，放在這一章最後一頁後面，自動產生一頁「自我檢查」。沒有題目的章就沒有這一頁。自動產生的頁不用寫進頁序。

## 給新人的按鈕和進度

每一頁下面有三個按鈕，不用另外做：

- **旁白**：打開這一頁的講稿，去掉【可略】【提示】段落；N 鍵和「講稿」按鈕是給講者的完整講稿。
- **看詳細和出處**：頁序裡這一頁有對應小節才出現，點了打開手冊網站的那一節。手冊的小節標題旁也有「看簡報」連回來。
- **問 Agent**：複製「哪個知識庫、哪一頁（頁 id）」，貼到 Claude Code 接著問。

看過的頁記在瀏覽器裡（`kif.<知識庫>.seen`），入口網站讀同一份紀錄，顯示每章看完了沒有。網址記頁 id（`deck.html#hk1`），舊的頁碼網址（`#36`）照樣能開。
