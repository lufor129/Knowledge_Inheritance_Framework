# 簡報

新人主要看簡報。每個知識庫都要有簡報，每個小節都要有簡報頁講到；簡報頁也可以講手冊沒寫的。新知識先做成簡報頁，一頁放不下的細節才寫手冊小節。

簡報和手冊一樣重要：查找時兩邊都算出處，說法不同時兩種都列。頁序 `kb/<知識庫>/deck/order.md` 記錄每一頁對應哪些小節，以及兩邊的指紋：哪一邊改了，檢查程式就點名另一邊要重看。

## 一邊改了：另一邊要跟上

check.py 會點名兩種情況：「對應的小節改過了」和「簡報頁改過了」。每一個被點名的頁都要：

1. 把頁和它對應的小節一起讀：`python3 framework/tools/read.py --here <知識庫> --page <頁id>`，它會列出對應的小節。
2. 說法不一致時，把沒改的那一邊改成一致：簡報頁是標題、結論、重點、數字卡、比喻、旁白；小節是內文。一致就不用改。
3. 改好或確認之後更新指紋：`python3 framework/tools/check.py --fp <知識庫> <頁id …>`，頁和小節的指紋一起更新。

指紋的意思是「有人對照過這一頁和這一節」，所以一定先對照過，再跑 `--fp`。

## 預覽

改了簡報頁，在本機建置這個分支的簡報、直接打開那一頁：`python3 framework/tools/get.py <知識庫> deck --here --open --page <頁id>`。傳承者確認、維護者審核都用這個看。

## 新增對應

新的小節有簡報頁在講時，在 order.md 那一頁後面加上 `→ <小節id>`（已經有對應就用逗號接在後面），再跑 `--fp`。每個小節都要有簡報頁講到，沒有的話檢查程式會擋。

## 做新的簡報頁

照半導體範例的樣子：

- 每頁講一個概念；標題下面一句話講結論。
- 右邊依序是重點（三到四點）、數字卡（一個數字；沒有好數字就放一句話重點）、比喻卡。
- 左邊放圖：會動、會變、有因果的概念做成可以操作的互動圖，先套樣板；其他可以用圖片、圖表、影片。
- 旁白是講稿：自學的人打開「旁白」看得到，講者按 N 看得到。

文字寫在 `deck/<部分>/<章>.md`，互動圖寫在 `deck/figures/*.js`。加進頁序 order.md 才會播放。

- 檔案：`kb/<知識庫>/deck/<數字-英文>/<兩位數字-英文>.md`，編號跟手冊一樣，例如 `deck/2-manufacturing/05-gate.md` 是第二部分第 5 章。`00-` 開頭的檔放部分的開場、總覽，不屬於任何一章。第一行寫 `# 章名`。
- 一頁是一個錨點加標題，底下是欄位：

  ```
  <a name="hk1"></a>
  ## 絕緣牆的兩難：電場要過得去，電子不要過去

  - 短標題：閘極絕緣層：電場過、電子不過
  - 英文：Gate Dielectric · High-k
  - 建議：5.2 分
  - 圖：hk1

  結論：閘極隔著一道絕緣牆，用**電場**控制通道……

  重點：
  - **電場要過得去**：牆越薄，閘極越控制得住通道
  - 牆每薄 0.2 nm，漏電大約多 10 倍[^hk1-1]

  數字卡：約 1.2 nm｜2000 年代初期二氧化矽已經薄到這裡

  比喻（wall）：隔著牆用磁鐵（閘極）吸鐵片（通道的電子）……

  旁白：
  第五章：閘極。回到電晶體的核心……

  [^hk1-1]: 出處：……
  ```

| 欄位 | 寫法 |
|---|---|
| 短標題、英文 | 總覽和講者視窗用的短標題；英文副標可以不寫 |
| 建議 | 這一頁大約講幾分鐘；入口網站用它算每章要看多久 |
| 圖 | 互動圖的名稱；或圖片、影片：`assets/img/檔名.jpg｜說明`、`assets/video/檔名.mp4｜說明`（要列進 assets/SOURCES.md） |
| 標籤、資料 | 標題旁的橘色標籤（例如「新技術」）；頁尾的「資料：」來源說明。可以不寫 |
| 結論 | 標題下面那一句 |
| 重點 | 三到四點，一行一點 |
| 圖說 | 樣板用的說明，一行一個「- 標題：說明」：一步步播放的每一步、結構圖的每個零件 |
| 數字卡 | `數字｜說明` |
| 比喻 | `比喻（圖示）：` 後面接文字；卡片標題不是「比喻」時寫 `比喻（圖示｜標題）：`。圖示名稱見 `framework/engine/widgets/anim.js` 的 ICON |
| 旁白 | 講稿，可以多段，空行分段；寫在欄位的最後，之後到註腳之前都算旁白。開頭寫【可略】【提示】的段落只給講者看 |

- 行內寫法：`**粗體**`、`` `程式` ``、`[文字](網址)`、`[^註腳]`，也可以直接寫 HTML。註腳是出處，名稱用「頁 id-編號」，定義寫在那一頁最後；頁面上數字後面會出現小標號，點了看出處，最後一頁自動整理成「出處」。
- 頁碼引用：要說「第幾頁」時寫 `[[頁:頁id]]`，顯示時換成「第 N 頁」，頁序調整了也不會錯。不要寫死頁碼。

### 互動圖：先套樣板

三種樣板在 `framework/engine/figures/templates.js`，寫法和例子都在檔案開頭：

| 樣板 | 什麼時候用 | 半導體的例子 |
|---|---|---|
| `Fig.canvas` | 拉桿看變化、切換比較 | 閘極那頁拖動絕緣牆厚度、切換材料 |
| `Fig.steps` | 一步步播放流程，每一步的說明寫在「圖說：」 | 環繞式電晶體的製造步驟 |
| `Fig.parts` | 可以點的結構圖，每個零件的說明寫在「圖說：」 | 電晶體的零件 |

```js
Fig.add('hk-wall', Fig.canvas({
  title: '閘極與通道之間', segs: [{ id: 'k', items: ['二氧化矽', '二氧化鉿'] }],
  sliders: [{ id: 't', label: '厚度', min: 0.6, max: 4, step: 0.1, value: 2.5, unit: ' nm' }],
  meters: [['hw-m', '漏電']],
  draw(c, w, h, v) { /* v.k 是第幾個切換、v.t 是拉桿的值 */ },
  update(el, v) { U.setMeter(el, 'hw-m', …); }
}));
```

套不上的才自己寫：`Fig.add('名稱', { render(頁) -> 左欄 HTML, init(el, ctx, 頁), meters, layout: 'w66' | 'w50' | 'full', side: false })`。輔助函式在 `framework/engine/widgets/core.js`、`anim.js`（`U.figHTML`、`U.range`、`U.seg`、`U.stepper`、`U.canvas`……）；`ctx.raf` 的動畫離頁自動停止。

版面特別的頁（例如全頁的表格、章節頁）寫 `body: true`，`render` 回傳整個內容區，右欄用 `U.pageSide({ top, meters, extra })` 放這一頁 Markdown 的重點、數字卡、比喻；`raw: true` 連標題都自己畫。`cls`、`eyebrow`、`back`、`hub` 這些頁面設定也寫在互動圖裡。半導體的互動圖（`kb/semiconductor/deck/figures/`）都是這種寫法，可以參考。

互動圖只畫圖、管操作；要讓新人讀的文字寫在 Markdown（重點、圖說、旁白），查找、搜尋和讀者測試才讀得到。

### 放影片

示範影片（例如物件偵測的結果）建置時會內嵌進單一 HTML，離線也能播：

- 影片放在 `kb/<知識庫>/assets/video/`，格式用 mp4（H.264）或 webm；和圖片一樣要列進 `assets/SOURCES.md`，寫說明和出處。
- 整支影片會塞進 HTML，所以只放幾秒鐘、去掉聲音、縮到需要的解析度，例如：`ffmpeg -i 原檔.mp4 -t 8 -an -vf scale=960:-2 -c:v libx264 -crf 28 -movflags +faststart assets/video/檔名.mp4`
- 整頁放一支影片：簡報頁寫 `圖：assets/video/檔名.mp4｜說明`。
- 放在互動圖裡：`U.video('assets/video/檔名.mp4')`，預設靜音、循環、進頁自動播放，點畫面暫停／繼續，離頁自動停止；要控制列或不要循環時加選項，例如 `U.video('assets/video/檔名.mp4', { controls: true, loop: false })`。

### 自我檢查題目

章檔最後可以加 `## 自我檢查`，格式跟手冊的常見問題一樣，`相關：` 寫頁 id；可以用 `### 主題` 分組，給業界人士的題目在題目前加 `【深入】`。建置時：

- 這一章的題目，加上手冊同一個編號那一章的常見問題（同一題只列一次），放在這一章最後一頁後面，自動產生一頁「自我檢查」。沒有題目的章就沒有這一頁。
- 所有章的題目照主題整理成問答附錄（`window.QA`）；全是【深入】題的主題歸在「進階」。

自動產生的頁不用寫進頁序。

## 給新人的按鈕和進度

每一頁下面有三個按鈕，不用另外做：

- **旁白**：打開這一頁的講稿，去掉【可略】【提示】段落；N 鍵和「講稿」按鈕是給講者的完整講稿。
- **看詳細和出處**：頁序裡這一頁有對應小節才出現，點了打開手冊網站的那一節。手冊的小節標題旁也有「看簡報」連回來。
- **問 Agent**：複製「哪個知識庫、哪一頁（頁 id）」，貼到 Claude Code 接著問。

看過的頁記在瀏覽器裡（`kif.<知識庫>.seen`），入口網站讀同一份紀錄，顯示每章看完了沒有。網址記頁 id（`deck.html#hk1`），舊的頁碼網址（`#36`）照樣能開。
