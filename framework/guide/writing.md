# 寫作、出處和 id

做或改簡報頁時照這份寫頁 id、自我檢查、出處、圖片和術語表；頁面的欄位、深入頁、速覽和先修的寫法在 framework/guide/deck.md。用詞照 GLOSSARY.md；章檔的範例在 framework/templates/chapter.md。

## 頁 id

- 每一頁（主頁、深入頁）開頭兩行固定：

  ```
  <a name="hk1"></a>
  ## 絕緣牆的兩難：電場要過得去，電子不要過去
  ```

- id 用小寫英文開頭，簡短好打（例如 `hk1`、`litho6`、`ocd`）；深入頁用主頁或主題的 id 加 `-d`（例如 `hk3-d`）。在同一個知識庫裡不能重複。
- 建立後**永遠不改名**。要改的是標題和內容，id 不動。
- 刪除或合併頁時，所有引用在同一個變更提案裡一起改掉，不留舊 id。引用有這幾種，找法：`git grep -n "<id>" -- kb/ framework/paths.md`。
  - 頁序 deck/order.md、章節列的第一頁
  - 深入頁的「深入：」
  - 自我檢查的「相關：」
  - 頁碼引用 `[[頁:<id>]]`、跳頁連結 `[文字](#<id>)`
  - 術語表的「第一次出現」
  - 角色路徑 framework/paths.md（寫成 `知識庫/id`）
  - 互動圖 `Fig.add('<id>'`

## 自我檢查

每個章檔最後可以加 `## 自我檢查`，用 `### 主題` 分組：

```
## 自我檢查

### 閘極的材料

<details>
<summary>電晶體會壞嗎？可以用多久？</summary>
正常使用可以用十年以上……
相關：hk1、hk2-d
</details>
```

- 答案收在 `<details>` 裡，讓新人先自己想。先講結論，再講原因。
- 最後一行寫 `相關：` 加上頁 id（主頁或深入頁），用「、」分隔。答案裡的說法要在這些頁裡找得到：自我檢查是複習用的摘要，知識本身寫在頁上。
- 給有業界經驗的人的題目是**深入題**：題目前加 `【深入】`。
- 只放有答案的題目。還沒有答案的問題是 issue（待回答），不寫進簡報；只有手動模式例外，寫成 `<summary>【待回答】題目</summary>`。

建置時，每一章的題目自動產生一頁「自我檢查」，放在那一章最後；所有題目也整理成問答附錄。

## 出處

- 每個數字、每個「研究指出」都要附出處註腳。註腳名稱用「頁 id-編號」，在同一個章檔裡不重複：

  ```
  牆每薄 0.2 nm，漏電大約多 10 倍[^hk2-d-1]。

  [^hk2-d-1]: 出處：論文、文件位置或網址
  ```

- 註腳定義寫在那一頁的最後。頁面上數字後面會出現小標號，點了看出處；最後一頁自動整理成「出處」。
- 出處的寫法：
  - 論文寫作者、標題、期刊、年份或 DOI；網頁寫標題和網址。
  - 新聞、業界媒體、部落格是報導，寫「出處（報導）：媒體，標題，日期，網址」。先找第一手來源（原廠文件、論文、官方網頁），找不到才用報導；標出來，讀者和維護者才知道這個說法有多可靠。
  - 公司文件寫文件名稱和放在哪裡。
  - 訪談寫「口述的人（部門）口述，YYYY-MM」。
- 找不到出處的數字就不寫，或改成不帶數字的說法。不要編出處。
- 這次新寫或改到的說法（結論、重點、圖說、數字卡、深入頁說明的每一段）有數字沒出處，檢查程式會擋；原本就有、還沒出處的，列在 `index.py <知識庫> --todo`，慢慢補。
- 整理別人的資料時，原檔不放進知識庫，只在出處寫明它在哪裡。

## 圖片

- 圖片放在 `kb/<名稱>/assets/img/`。整頁放一張圖寫 `- 圖：assets/img/檔名.jpg｜說明`；深入頁的說明裡，自己一行寫 `![說明](assets/img/檔名.jpg)`。
- 每張圖片都要列進 `assets/SOURCES.md`：檔名、說明、出處。不在清單上的圖片不能用。只寫出處，不用寫授權。

## 術語表

- `kb/<名稱>/terms.md` 一列一個術語：中文、英文、一句話解釋、第一次出現在哪一頁（頁 id；還沒有頁就寫「（待補）」）。
- 新增知識時，有新術語就順便加一列。入口網站的主題索引從這張表自動產生：術語的中文、英文或縮寫出現在哪幾頁。

## 寫作：ELI5

讀者是沒有背景的新人。方向是 ELI5，要多白話由內容決定：

- 先講白話，再講術語。術語第一次出現附英文，例如「量子穿隧（Quantum Tunneling）」。
- 能用生活比喻就用一個。
- 一頁講一個概念；先講「為什麼要知道這個」，再講細節。細節多到一頁放不下，做成深入頁。
- 寫得清不清楚，由讀者測試判斷（framework/guide/reader-test.md），不是靠這份清單。
