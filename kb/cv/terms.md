# 術語表

| 中文 | 英文 | 一句話解釋 | 第一次出現 |
|---|---|---|---|
| 電腦視覺 | Computer Vision | 讓機器處理、理解影像和影片的領域 | （待補） |
| 相機模型 | Camera Model | 用數學描述 3D 世界的點怎麼投影成照片上的像素 | （待補） |
| 特徵 | Feature | 影像裡容易辨認、可以拿來比對的局部資訊，例如角點 | （待補） |
| 卷積神經網路 | Convolutional Neural Network, CNN | 用小視窗在影像上滑動擷取局部圖樣的神經網路 | （待補） |
| 視覺 Transformer | Vision Transformer, ViT | 把影像切成小塊，用注意力機制看各塊之間關係的模型 | （待補） |
| 影像分類 | Image Classification | 判斷整張影像屬於哪一類 | （待補） |
| 物件偵測 | Object Detection | 找出影像裡每個物體的位置（框）和類別 | （待補） |
| 影像分割 | Image Segmentation | 逐個像素標出它屬於哪個類別或哪個物體 | （待補） |
| 深度估計 | Depth Estimation | 推算影像中每個點離相機多遠 | （待補） |
| 物件追蹤 | Object Tracking | 在影片的連續畫面裡持續跟住同一個物體 | （待補） |
| 標註 | Annotation | 人替資料加上正確答案（類別、框、遮罩），供模型學習 | （待補） |
| 模型壓縮 | Model Compression | 讓模型變小變快、盡量不掉準確度的技術，例如量化、剪枝 | （待補） |
| 自監督學習 | Self-supervised Learning | 不靠人工標註，從資料本身造出學習目標的訓練方式 | （待補） |
