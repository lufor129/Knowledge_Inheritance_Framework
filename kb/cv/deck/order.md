# 頁序

簡報的頁面清單：由上到下就是播放順序。頁面寫在 deck/<部分>/<章>.md（寫法見 framework/guide/deck.md），加進這裡才會播放。
有對應小節的頁寫成「- 頁id@頁的指紋 → 小節@指紋, 小節@指紋」：哪一邊改了，檢查程式就點名另一邊要重看。指紋由 check.py --fp 產生，人不用手改。
章節列照簡報章檔的「# 章名」自動產生；要另外編排時，才加一段「## 章節列」，一行寫「- 編號：章名 → 第一頁 id」。
