給剛進團隊、會寫 Python 但沒做過電腦視覺專案的工程師與研究生：讀完能依任務選方法、讀懂主流模型架構，並從資料準備、訓練、評估做到部署。

## 全景圖

```mermaid
flowchart LR
  A[基礎<br>影像怎麼來、怎麼處理] --> B[深度學習模型<br>兩種骨幹架構]
  B --> C[任務<br>用模型解決具體問題]
  C --> D[實務<br>做成能上線的系統]
  A1[影像形成與相機模型] --> A2[傳統影像處理] --> A3[特徵與比對]
  B1[卷積神經網路] --> B2[Vision Transformer]
  C1[影像分類] --> C2[物件偵測] --> C3[影像分割]
  C3 --> C4[3D 視覺與深度估計] --> C5[影片與追蹤]
  D1[資料集與標註] --> D2[訓練與評估] --> D3[模型壓縮與部署]
  A1 -. 相機幾何 .-> C4
  A3 -. 特徵比對 .-> C5
  D2 -. 評估結果回頭修正資料 .-> D1
```

第一部分是深度學習之前的底子：相機模型會在 3D 視覺用到，特徵比對會在追蹤用到。第二部分介紹兩種骨幹架構，第三部分的各種任務都建在這兩種骨幹上。第四部分把模型做成產品，評估出來的結果常常會回頭修正資料。
