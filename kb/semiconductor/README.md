# 半導體製程

給半導體新人的知識庫：從電晶體結構演進、十章製程與量產，到先進封裝與背面供電。

## 全景圖

```mermaid
flowchart LR
  A[演進與現況<br>電晶體怎麼越做越小] --> B[製造：從電晶體到量產<br>十章製程]
  B --> C[突破摩爾定律<br>先進封裝、背面供電]
  B1[微影] --> B2[蝕刻] --> B3[沉積] --> B4[摻雜磊晶] --> B5[閘極]
  B5 --> B6[平坦化] --> B7[環繞式] --> B8[模擬] --> B9[檢測量測] --> B10[設計到量產]
  B9 -. 量到的數字回頭修正 .-> B1
```

第二部分的十章照一片晶圓實際走過的順序排；檢測量測量到的數字，會回頭修正前面的製程。

## 搬遷進度

手冊從原本的半導體簡報一章一章抽出來，每章一個變更提案；第一批是微影、閘極、檢測量測。還沒抽出的章仍在簡報裡，簡報照舊能播。
